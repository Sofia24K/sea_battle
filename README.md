# Морський бій ⚔️
Консольна реалізація гри «Морський бій» на мові **C++**.

## 📝 Опис проєкту
Це курсова робота з дисципліни «Програмування»
Гра повністю відтворює класичні правила «Морського бою»:
- поле 10×10
- флот: 1 чотирипалубний, 2 трипалубних, 3 двопалубних, 4 однопалубних кораблі
- кораблі не можуть торкатися один одного (включаючи діагоналі)
- влучання → додатковий хід
- гра для двох гравців на одному комп’ютері
  
## ✨ Основні можливості
### ✅ Реалізовано
- Головне меню з правилами гри
- Автоматичне та ручне розміщення кораблів
- Повноцінна гра для двох гравців по черзі
- Кольорова консоль (зелений — кораблі, червоний — влучання, синій — промах)
- Перевірка валідності координат (наприклад: `B5`, `A10`)
- Захист від повторних пострілів в одну клітинку
- Визначення потоплення кораблів
- Оголошення переможця
### ❌ Не реалізовано (майбутні покращення)
- Гра проти комп’ютера (AI)
- Збереження/завантаження гри
- Звукові ефекти
- Зміна розміру поля
